Metric Definitions

Highest Priority Sources: There is no limit on the number of sources that can be mapped, however, clients will likely timeout before more than 8 sources can be checked. These calculations consider only the 8 highest priority sources for each channel as determined for playback, representing the real-world metrics. Manual priority takes precedence, with quality score as a secondary factor.

Health (Overall Uptime): Calculates the total probability that the channel will be online using the Highest Priority Sources.

Lowest Uptime: Shows the uptime of the single least reliable source from the Highest Priority Sources. This helps identify the "weakest link" in your channel's mappings.

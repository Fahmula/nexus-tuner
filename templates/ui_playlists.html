How Playlists Work

Playlists: Each playlist is its own M3U and HDHomeRun tuner built from your logical channels and provider groups, so you can give different people or devices different lineups. All playlists share the same provider stream limits, and viewers watching the same channel share a single stream.

Logical Channel Groups: Include all except includes every logical channel group except the ones you select, new groups are included automatically. Only include includes just the groups you select.

Provider Groups: Select groups straight from your providers' M3Us without creating logical channels. The same group from multiple providers is merged, and channels with the same name become one channel that fails over between providers. Names are matched ignoring case and surrounding spaces.

URLs: The URLs below use the address you are viewing this page with ({{ detected_base_url }}). Clients always get URLs matching the address they connected with, e.g. someone connecting through your Tailscale IP gets Tailscale URLs inside the playlist. Set a Base URL on a playlist to always use a fixed address instead.

HDHomeRun: Add the HDHomeRun URL as a tuner in Emby, Jellyfin, or Plex. It only contains logical channels with a channel number, channels from provider groups are only available in the M3U for now. Some clients such as Plex may only accept an address without a path, the Main playlist uses the root address for this reason.

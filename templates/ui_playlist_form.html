Building a Playlist

Logical Channel Groups: Groups come from the Group Title of your logical channels. With Include all except, the selected groups are excluded and any new group is included automatically. With Only include, only the selected groups are included.

Provider Groups: Selected groups add their channels straight from the provider M3Us. Groups with the same name across providers are shown once, and channels with the same name inside them become a single channel with a source from each provider. These channels obey provider limits, share streams between viewers and fail over like logical channels. They are only in the M3U, not HDHomeRun, for now.

Base URL: Leave empty to use the address each client connects with, e.g. {{ detected_base_url }} for you right now. Set it to always use a fixed address, such as your Tailscale IP or a domain behind a reverse proxy.

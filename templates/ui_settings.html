Media Servers

Emby & Jellyfin Servers

The ghost session monitor stops streams that no enabled server is playing, e.g. when a client stopped watching but left its connection open. Add every Emby or Jellyfin server that watches through this tuner, including ones at other locations, or their viewers will be stopped.

  • Channels are matched by name, keep the channel names in each server the same as in NexusTuner.
  • If an enabled server cannot be reached, no streams are stopped until it is reachable again.
  • Changes apply immediately and run a check straight away.
